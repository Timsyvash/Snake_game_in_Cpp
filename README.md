# 🐍 Classic Snake Game in C++

Проста та захоплива реалізація класичної гри **"Змійка"** для Windows Console, написана мовою C++. Проєкт створено в навчальних цілях для практичного освоєння базових алгоритмів, роботи з консольним рендерингом, обробки введення в реальному часі та керування пам'яттю (робота з масивами для хвоста змійки).

---

## 🎮 Ігровий процес (Gameplay)

У грі ви керуєте змійкою (`O`), яка повинна їсти фрукти (`F`). З кожним з'їденим фруктом довжина хвоста змійки (`o`) збільшується, а ваш рахунок зростає на 10 балів. 

*Увага: гра закінчується, якщо змійка врізається в стіну (`#`) або у власний хвіст!*

> **Порада:** Ви можете додати сюди гіфку або скріншот своєї гри! Наприклад:

## 🛠 Особливості проєкту (Features)

* **Рендеринг у реальному часі:** Карта гри оновлюється динамічно за допомогою консольного очищення та затримки (`Sleep`).
* **Асинхронне введення:** Використання функції `_kbhit()` та `_getch()` з бібліотеки `<conio.h>` дозволяє змійці рухатися безперервно, навіть якщо гравець не натискає клавіші.
* **Логіка хвоста:** Хвіст змійки реалізовано за допомогою динамічного зміщення координат у масиві, де кожен елемент слідує за попереднім.
* **Сумісність з Unicode:** Використання UTF-8 кодування (`SetConsoleCP(65001)`) для коректного відображення символів у консолі.

## 🕹 Керування (Controls)

Керування змійкою здійснюється за допомогою класичної розкладки **WASD**:

| Клавіша | Напрямок руху |
| :---: | :--- |
| **W** | Вгору (Up) |
| **A** | Ліворуч (Left) |
| **S** | Вниз (Down) |
| **D** | Праворуч (Right) |
